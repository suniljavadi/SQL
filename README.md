# SQL Practice and Case Studies

**Status: Learning project**

A collection of SQL Server/T-SQL scripts covering fundamentals, functions, customer orders, employee data, and a software-programmer case study with more than 100 practice queries.

## Contents

- `Basics of SQL.sql` for foundational syntax
- `Customer_orders.sql` for customer and order analysis
- `Employee Case Study Project.sql` and `EmployeeDetails.sql` for employee scenarios
- `Software Programmer Case Study-100+ sql queries.sql` for extended query practice
- `SQL Function.sql` for function examples
- `sqlassignment.sql` for assignment exercises

## How To Use

Open the scripts in SQL Server Management Studio or another T-SQL-compatible editor. Review the table definitions and sample data assumptions in each file before executing queries. No database schema deployment script or automated test harness is included.

## Skills Demonstrated

- Filtering, joins, grouping, and subqueries
- Case-study-oriented analytical query design
- SQL Server/T-SQL syntax and functions
- Translating business questions into queries

## Limitations and Future Improvements

Add schema and seed scripts, expected-result fixtures, query-performance notes, data-quality cases, and a repeatable test runner. The repository does not claim production database deployment or benchmarked query performance.
